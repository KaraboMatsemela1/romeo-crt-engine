# CRT Glossary

No glossary term is assumed verified until source evidence is added. `PROVISIONAL` means the concept is source-backed enough for research use but not yet deterministic/production-safe.

| Term | Working definition | Status | Evidence |
|---|---|---|---|
| CRT | Candle Range Theory; broader formal definition still being established from the corpus. | PROVISIONAL | ROMEO-2024-CRT |
| Range | A bounded price interval; Romeo's CRT foundation appears to treat a candle itself as a range, but exact eligible-range semantics remain unresolved. | PROVISIONAL | ROMEO-2024-CRT |
| Liquidity | Observable trading interest/stops associated with reference highs/lows and other later-defined levels. Do not encode assumptions about participant intent. | PROVISIONAL | ROMEO-2024-TS 06:29–15:54 |
| Old high / old low | A previously established price extreme used as the reference level for a Turtle Soup event. Eligibility criteria remain unresolved. | PROVISIONAL | ROMEO-2024-TS 06:29, 11:06, 15:18 |
| Turtle Soup | Failed excursion beyond a qualifying prior high/low followed by movement in the opposite direction. Exact confirmation and timing rules remain unresolved. | PROVISIONAL | ROMEO-2024-TS 06:29–15:54 |
| Sweep / manipulation | Price trades beyond a qualifying reference extreme. A sweep alone is not yet sufficient to define a completed Turtle Soup setup. | PROVISIONAL | ROMEO-2024-TS 11:43, 13:57, 15:54 |
| False breakout / breakdown | A move beyond a prior reference high/low that does not sustain continuation and instead reverses. | PROVISIONAL | ROMEO-2024-TS 06:29–15:54 |
| Confirmation | The observable event that establishes failure of continuation and makes a setup actionable. Exact Romeo semantics remain unresolved. | UNRESOLVED | ROMEO-2024-TS identifies the need conceptually; later sources required |
| Model #1 | Romeo's later candle-specific setup/entry model. Deterministic definition not yet frozen. | PROVISIONAL | ROMEO-2025-S1 |
| Kiss of Death (KOD) | A specialized Turtle Soup occurring late in an active CRT journey; Romeo defines it as the final Turtle Soup before the target is hit. Episode 5 also associates KOD-like behavior with a fake pre-key-level reversal, so KOD roles require reconciliation before a global predicate is defined. | PROVISIONAL | ROMEO-2025-S2 01:49, 06:12; ROMEO-2025-S5 12:13–14:26 |
| Candle 1 / 2 / 3 | Provisional CRT sequence mapped to accumulation / manipulation / distribution. Episode 7 adds a high-confidence causal gate: Candle 2 must be complete before Candle 3 becomes eligible, but the exact live predicates for identifying the sequence remain unresolved. | PROVISIONAL | ROMEO-2025-S2; ROMEO-2025-S3; ROMEO-2025-S7 |
| CRT journey | Stateful progression of a parent higher-timeframe CRT from range/accumulation through manipulation toward target delivery, with lower-timeframe events used for execution. | PROVISIONAL | ROMEO-2025-S3 02:31–16:21 |
| True MSS | Romeo's `true market structure shift`. Episode 5 contrasts it with fake MSS-like patterns before the actual key level and associates the true shift with the real key-level interaction and correct time. Exact deterministic definition remains unresolved. | PROVISIONAL | ROMEO-2025-S3 10:20–14:10; ROMEO-2025-S5 12:13–15:51 |
| CRT 50% | Midpoint of the parent CRT range. It is repeatedly important, but Episode 7 indicates it must not be forced as a universal mandatory touch before entry; role may vary by setup/regime. | PROVISIONAL | ROMEO-2025-S2; ROMEO-2025-S7 |
| Opposite CRT extreme | The opposite boundary of the selected parent CRT range; demonstrated as a later objective in the bearish KOD example and part of journey destination logic. | PROVISIONAL | ROMEO-2025-S2; ROMEO-2025-S3 |
| FVG confluence | Fair Value Gap aligned around an old extreme; presented as useful KOD confluence, not yet established as mandatory. | PROVISIONAL | ROMEO-2025-S2 17:39–17:57 |
| HTF context / LTF execution | Higher timeframe supplies parent CRT context/journey; lower timeframe supplies entry/confirmation evidence. Exact timeframe-pair mapping remains unresolved. | PROVISIONAL | ROMEO-2025-S3; ROMEO-2025-S7 |
| Trade candle / parent candle | The explicitly selected higher-timeframe candle whose lifecycle/range anchors the CRT analysis before lower-timeframe patterns are considered. Initial public scope is H4, D1 and W1. | PROVISIONAL | ROMEO-2025-S4 |
| Candle anatomy | A candle's opening time, closing time and price movement between those boundaries; for causal testing the anatomy must be observed as it evolves, not only after close. | PROVISIONAL | ROMEO-2025-S4 |
| Candle snapshot | Project engineering term for the information actually known about an active candle at timestamp `t`: open, high-so-far, low-so-far, current price and scheduled close; final OHLC is unavailable until close. | ENGINEERING CONSTRAINT | Derived from ROMEO-2025-S4 candle lifecycle + anti-look-ahead requirement |
| Initial parent timeframe whitelist | H4, D1 and W1 are the initial allowed parent/trade candles. When discussing top-down hierarchy, use W1 → D1 → H4; the whitelist itself is a set, not an ordered requirement. | PROVISIONAL | ROMEO-2025-S4 |
| Candle boundary | The timezone/session-specific open and close timestamps used to construct H4/D1/W1 bars. Exact Romeo-aligned anchors remain unresolved and are strategy-critical. | UNRESOLVED | ROMEO-2025-S4 establishes time boundaries as part of candle anatomy |
| Key level | Higher-timeframe price/time context where a meaningful reaction is expected; it is not an entry by itself and must be combined with journey/location/timing and lower-timeframe behavior. Exact marking hierarchy remains unresolved. | PROVISIONAL | ROMEO-2025-S5 |
| Destination key level | Project research label for a key level price is actively traveling toward; Romeo explicitly permits trading the journey into the level. | PROVISIONAL | ROMEO-2025-S5 |
| Reaction-origin key level | Project research label for a key level after it is reached and becomes the location from which a reversal/expansion trade may originate. | PROVISIONAL | ROMEO-2025-S5 |
| Fake MSS | MSS-like lower-timeframe reversal structure appearing before the true key-level interaction; Romeo warns this can trap premature entries. Exact formal definition unresolved. | PROVISIONAL | ROMEO-2025-S5 |
| Time key level | A key level defined partly or wholly by time rather than only by a price coordinate. Exact taxonomy and timing rules remain unresolved. | PROVISIONAL | ROMEO-2025-S5 |
| SMT | Cross-market divergence/context concept comparing related instruments around corresponding highs/lows. Episode 6 indicates SMT should not be blindly traded and should be combined with CRT/key-level context plus confirmation. Exact pair polarity, direction mapping and mandatory/optional status remain unresolved. | PROVISIONAL | ROMEO-2025-S6; first-party Telegram follow-up |
| SMT pair / group | A predeclared set of related instruments used for SMT comparison, such as index, metals, crypto or FX-linked examples. Pair relationship must be versioned and source-backed before testing. | PROVISIONAL | ROMEO-2025-S6 |
| SMT divergence | Cross-market state where one related instrument takes a corresponding high/low while another does not. Exact directional meaning depends on relationship semantics that are not yet frozen. | PROVISIONAL | ROMEO-2025-S6 |
| Cross-market manipulation evidence | Project research abstraction allowing manipulation evidence to come from either a local Turtle Soup or a qualifying SMT event in a related market. This substitution hypothesis is source-directed but not yet deterministic. | HYPOTHESIS | ROMEO-2025-S6 + first-party Telegram statement that expected local Turtle Soup did not occur because SMT played its role |
| Synchronized multi-market replay | Backtesting requirement for SMT-enabled strategies: all related instruments must be replayed on a common causal timeline with stale-data/session guards so future or delayed information cannot create false divergences. | ENGINEERING CONSTRAINT | Derived from ROMEO-2025-S6 cross-market semantics + anti-look-ahead requirements |
| Candle 2 close gate | Explicit temporal boundary after which Candle 3 may become eligible. Candle-3 logic must not be evaluated while Candle 2 is still active. | PROVISIONAL / HIGH CONFIDENCE | ROMEO-2025-S7 |
| Candle 3 eligibility | State beginning after a valid Candle 2 has completed and the next candle opens; eligibility is not equivalent to an entry signal. Key-level/context and confirmation still apply. | PROVISIONAL | ROMEO-2025-S7 |
| OTE / 50% state | Retracement/location context used around Candle 3. The 50% midpoint is important, but Episode 7 indicates valid key-level liquidity behavior may justify acting without an exact 50% touch. Exact OTE anchors/tolerances remain unresolved. | PROVISIONAL | ROMEO-2025-S7 |
| No-signal terminal state | Project state for a valid CRT journey that never produces the required Candle-3 entry/confirmation. The system records/journals the miss rather than forcing a trade. | PROVISIONAL / ENGINEERING GOVERNANCE | ROMEO-2025-S7 |
