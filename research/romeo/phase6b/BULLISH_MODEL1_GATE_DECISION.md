**Gate:** `6B-1`

**Executable:** **NO**

## Decision

The bullish D1 -> H1 Model #1 research path is preserved as a legitimate future research hypothesis, but it does not currently satisfy the project's evidence standard for deterministic specification.

The direct-source search established that bullish CRT states are part of Romeo's doctrine and strengthened the general CRT-high/low to 50% relationship. It also confirmed first-party provenance for Episode 1 as the intended Model #1 technical source. Independent indexed transcript/summary extractions strongly converge on a bullish Model #1 inverse.

However, the accessible first-party source record did not close all strategy-critical predicates required for an order path without relying on code symmetry or secondary interpretation.

Therefore:

```text
GATE 6B-1                         EVIDENCE_INSUFFICIENT
V0.2 BULLISH SPECIFICATION        NOT AUTHORIZED
V0.2 BULLISH ALPHA IMPLEMENTATION NOT AUTHORIZED
V0.2 BULLISH HISTORICAL BACKTEST  NOT AUTHORIZED
```

## What was established

### First-party supported

- bullish CRT states exist and can invalidate an earlier bearish expectation;
- CRT highs/lows to the 50% is a source-backed opportunity relationship;
- Model #1 is an important public execution model;
- Episode 1 is the canonical public technical lecture for Model #1;
- the D1 -> H1 Model #1 mapping is strongly corroborated by the existing corpus.

### Strongly corroborated but not promoted to an executable rule

Indexed Episode-1 material consistently describes a bullish inverse involving:

```text
old-low interaction
+ qualifying down-close Model #1 candle
+ later close above the selected model candle
```

This is useful discovery evidence, not sufficient primary semantic closure under the project's current evidence policy.

## Critical predicates still unresolved

### 1. Bullish parent reference / CRTL lifecycle

The available first-party record does not establish the exact rule that makes the rolling C1 `CRTL` the owning bullish reaction reference for this candidate, including freshness, consumption, and parent ownership.

### 2. Bullish Candle-2 manipulation/reclaim

The project cannot safely promote the mirror:

```text
C2.low < C1.low
C2.high <= C1.high
C2 closes inside C1
```

merely because it is the mathematical inverse of the bearish v0.1 rule.

The exact sweep/reclaim and double-sweep semantics remain unclosed.

### 3. Exact bullish Model #1 confirmation reference

A later close-above confirmation is strongly corroborated, but the exact selected-candle price reference, timing, and any retrace requirement are not sufficiently primary-verified.

### 4. Structural stop owner

The source record supports structural protection below a bullish Turtle-Soup/structural low, but it does not close whether the owning object for this candidate is the parent sweep low, Model #1 low, Turtle-Soup low, or another exact structure.

### 5. Setup-specific target lifecycle

`CRTH/L -> 50%` is source-backed broadly, but the exact relationship between the selected bullish Model #1 subtype, C1 midpoint, pre-entry consumption, and Candle-3 expiry remains insufficiently specified.

### 6. Direction-neutral parameter inheritance

The project cannot assume that the bearish v0.1 `body/full_range >= 0.50` formalization or every execution parameter should automatically transfer into the bullish candidate without a new freeze decision.

## Why the gate fails closed

The unresolved fields sit directly on the signal/order path. Filling them by symmetry would violate the project rule:

```text
CODE SYMMETRY != SOURCE EVIDENCE
```

The Phase-6 failure mode was insufficient sample size. That result creates a particularly high risk of unconsciously choosing mirror rules because they increase opportunity count.

The project therefore prefers preserving an incomplete candidate over creating an apparently precise but source-invented strategy.

## What this decision does not mean

This decision does **not** mean:

- bullish CRT is false;
- bullish Model #1 is invalid;
- Romeo does not trade bullish setups;
- the hypothesis is rejected on profitability grounds.

No bullish historical outcome was opened for this candidate.

The decision means only that the current accessible evidence is insufficient to meet the deterministic specification standard.

## Re-entry condition

This path may be reopened only if new direct evidence closes the missing predicates, for example:

- accessible original Episode-1/9 transcript/caption evidence;
- source chart frames with unambiguous labels/timestamps;
- first-party posts explicitly defining the missing bullish reference/confirmation/stop semantics.

If reopened, the existing failed gate remains preserved and a new evidence pass must reference this decision.
